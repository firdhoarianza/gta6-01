# Solara Bay — Low Tide

A browser-based, original open-world crime sandbox built with Three.js (vendored locally). Start a local server with `node serve.ts` and visit `http://localhost:8080`.

## Controls

| Action | Controls |
| --- | --- |
| Walk / drive | W A S D or arrow keys |
| Sprint | Shift |
| Jump / handbrake | Space |
| Enter / exit vehicle, interact with mission marker | E |
| Fire | Mouse button |
| Select pistol / SMG / shotgun | 1 / 2 / 3 |
| Reload | R |
| Crouch | F |
| Vehicle horn | H |
| Next radio station | N |
| Pause | P or Escape |
| Toggle weather (debug) | T |
| Side activity | M |

Click Enter the City to enable audio and begin. Progress is saved locally in the browser.
